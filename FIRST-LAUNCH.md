# Первый запуск Donorcraft на Windows

Этот файл — контрольный список первого запуска. Он специально отделяет то, что уже умеет исходный лаунчер Horizon, от того, что ещё должен собрать и проверить проект Donorcraft.

## Важно: готового запускаемого релиза пока нет

На данный момент GitHub Actions собирает предварительные файлы, но не полный игровой комплект. Архив **Donorcraft-Launcher-Windows-x64.zip** — только лаунчер; архив **Donorcraft-Game-Windows-x64-Preliminary** — проверка компиляции, а не готовая игра. Не считайте их установщиком или рабочим игровым клиентом. Сначала проект должен получить полный набор оригинальных exporter-ресурсов и пройти реальный запуск на Windows.

Проверять публикацию можно на странице [Releases](https://github.com/troll2281488/Donorcraft/releases) и состояние сборки — на странице [Actions](https://github.com/troll2281488/Donorcraft/actions).

## Что понадобится для первого игрового запуска

- Windows 10/11 x64.
- Собственная легально приобретённая Minecraft: Java Edition. Donorcraft/Horizon не распространяет игровые файлы Mojang.
- Установленная и хотя бы один раз запущенная версия Minecraft **26.3**, чтобы официальный лаунчер создал необходимые локальные файлы.
- Java **25**. Лаунчер должен проверить её наличие и сообщить, если нужна установка.
- Свободное место для клиента, библиотек, ресурсов и миров; не устанавливайте игру в папку, доступ к которой ограничен Windows.

## Когда появится полноценный релиз

1. Откройте [Releases](https://github.com/troll2281488/Donorcraft/releases) и скачайте только архив Windows x64, помеченный как полноценный релиз. Не используйте preliminary/compile-only артефакты.
2. Распакуйте архив в обычную папку пользователя, например `%LOCALAPPDATA%\\Programs\\Donorcraft`. Не запускайте игру прямо из ZIP.
3. Запустите `DonorcraftLauncher.exe`. При первом запуске проверьте путь к папке данных в Settings.
4. На странице Versions установите опубликованную совместимую версию Donorcraft.
5. На странице Play выберите подготовку из собственной установки Minecraft. Если лаунчер предложит войти в учётную запись для загрузки файлов Mojang, используйте только официальный вход и только если владеете игрой.
6. Дождитесь окончания подготовки. Не закрывайте лаунчер во время проверки Java, библиотек и игровых ресурсов.
7. Нажмите Play и создайте новый одиночный мир. Сначала проверьте одиночную игру, управление, звук и сохранение/повторное открытие мира.
8. После выхода убедитесь, что мир появился в Worlds. Перед экспериментами с модами или сетевой игрой сделайте резервную копию мира.

Если версия не появляется в Versions, подготовка завершается ошибкой или клиент не стартует, сохраните текст ошибки и лог со страницы Play. Не скачивайте случайные JAR-файлы и игровые ресурсы с зеркал.

## Игра с другом после проверки одиночного режима

Оба игрока должны использовать одну и ту же совместимую сборку. В игровом мире откройте паузу → Friends → Start Sharing и отправьте код приглашения другу приватно. Друг выбирает Friends → Join a Friend и вводит код. Хосту нужно оставить мир открытым.

## Если у друга слабый интернет

- Сначала проверьте соединение в одном и том же игровом билде; не меняйте одновременно версию и сетевые настройки.
- Хосту стоит уменьшить дальность прорисовки и simulation distance, а также не запускать параллельно большие загрузки.
- По возможности используйте Ethernet вместо Wi‑Fi; если только Wi‑Fi — подойдите ближе к роутеру.
- При кратком обрыве повторно подключитесь по новому/действующему приглашению, если игра это позволяет.
- Если прямое соединение не проходит из-за NAT, может помочь VPN-сеть или настроенный relay. В проекте пока нет гарантированно доступного публичного Donorcraft relay-сервера.
- Низкая скорость и высокий ping не исчезают от одного только relay: он может помочь установить маршрут, но не гарантирует отсутствие задержек, рывков или разрывов.

Не отключайте брандмауэр Windows целиком и не публикуйте код приглашения открыто.

## Что ещё не подтверждено

До полноценного релиза необходимо: собрать игру вместе с требуемыми exporter-ресурсами; упаковать все необходимые исполняемые файлы; проверить установку и подготовку на чистой Windows x64; запустить новый одиночный мир; проверить повторное открытие сохранения; затем проверить приглашение другу и сетевую игру при нестабильном соединении. Пока эти проверки не пройдены, проект нельзя честно называть готовым к первому запуску.
