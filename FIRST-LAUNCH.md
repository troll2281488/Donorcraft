# Первый запуск Donorcraft на Windows

## Что уже можно использовать

Отдельного игрового бинарника Donorcraft пока нет. Но лаунчер уже настроен получать **подписанные игровые сборки Horizon** из официального upstream-репозитория `horizon-rust/horizon`. Это самый короткий путь к первому запуску, не дожидаясь отдельного релиза Donorcraft.

Важно различать два архива:

- **Donorcraft-Launcher-Windows-x64.zip** — только приложение-лаунчер.
- **Donorcraft-Game-Windows-x64-Preliminary** — предварительная компиляция из форка, не готовый игровой клиент. Не запускай его вместо полноценной сборки.

Лаунчер сам скачивает совместимую сборку игры из upstream Releases и проверяет подписи/контрольные суммы перед установкой.

## Что понадобится

- Windows 10/11 x64.
- Собственная легально приобретённая Minecraft: Java Edition. Donorcraft/Horizon не распространяет игровые файлы Mojang.
- Версия Minecraft **26.3**, установленная и хотя бы один раз запущенная через официальный лаунчер.
- Java **25**. Если её нет, сначала проверь подсказку на странице Play: некоторые версии лаунчера умеют предложить подготовку Java автоматически.
- Свободное место для клиента, библиотек, ресурсов и миров.

## Порядок первого запуска

1. Получи `DonorcraftLauncher.exe` из успешной Windows-сборки в [GitHub Actions](https://github.com/troll2281488/Donorcraft/actions). Нужен артефакт **Donorcraft-Launcher-Windows-x64**, а не Preliminary Game. Если сборка ещё выполняется или завершилась ошибкой, дождись успешной.
2. Распакуй ZIP в обычную папку пользователя, например `%LOCALAPPDATA%\\Programs\\Donorcraft`. Не запускай exe прямо из архива.
3. Запусти `DonorcraftLauncher.exe`. На странице Versions обнови список и установи текущую Nightly из подключённого upstream-репозитория Horizon. Это будет сборка Horizon, устанавливаемая лаунчером Donorcraft, а не отдельный релиз форка.
4. Убедись, что Minecraft 26.3 уже установлен и один раз запущен через официальный лаунчер.
5. Открой страницу Play и выбери подготовку из собственной установки Minecraft. Лаунчер должен проверить Java, файлы игры, библиотеки и ресурсы. Если он предлагает официальный вход для загрузки файлов Mojang, используй его только при наличии собственной лицензии.
6. Дождись окончания подготовки и посмотри, чтобы в журнале не осталось ошибки.
7. Нажми Play, создай новый одиночный мир и проверь движение, звук, загрузку чанков.
8. Выйди в меню, закрой игру штатно и снова открой мир. Убедись, что сохранение работает и отображается на странице Worlds.
9. Сделай резервную копию мира перед сетевыми тестами и модами.

Если Versions пустая — нажми обновить список и проверь подключение к GitHub. Если установка не проходит проверку подписи, не обходи проверку и не скачивай ZIP с зеркал: сохрани текст ошибки и открой [Issues](https://github.com/troll2281488/Donorcraft/issues).

## Игра с другом

После успешного одиночного запуска:

1. Оба игрока устанавливают одну и ту же совместимую сборку.
2. Хост открывает свой одиночный мир, нажимает Esc → Friends → Start Sharing.
3. Отправляет код приглашения другу лично. Код действует как временный пароль — не публикуй его.
4. Друг открывает Friends → Join a Friend и вставляет код.
5. Хост не закрывает мир, пока они играют.

## Если у друга слабый интернет

Система Horizon сначала пробует прямое соединение по адресам из приглашения. Если в приглашении указан relay, игра может автоматически перейти на него, когда прямой путь не сработал. Relay помогает пройти NAT/CGNAT, но **не ускоряет интернет** и не устраняет высокий ping.

Техническая документация Horizon оценивает передачу через relay примерно в 10–50 КБ/с при обычной игре; при быстром открытии незнакомой местности трафик может кратковременно вырасти до нескольких сотен КБ/с. Пропускная способность ограничивается на уровне сессии.

Что реально помогает:

- Если слабый интернет у гостя, закройте фоновые загрузки, видео и облачную синхронизацию на его ПК.
- Если слабый интернет у хоста, по возможности пусть мир откроет игрок с более стабильной исходящей скоростью: хост отправляет игровые данные гостю.
- Подключите ПК кабелем Ethernet, если это возможно; иначе используйте стабильный Wi‑Fi рядом с роутером.
- Для первого теста оставьте одного гостя, не летайте быстро по новым территориям и не запускайте параллельно большие загрузки.
- Если прямой путь не устанавливается, попробуйте одну приватную VPN-сеть (например, Tailscale/ZeroTier) или собственный relay.
- У Donorcraft пока нет обещанного публичного relay-сервера. Один из игроков должен сам запустить `horizon-relay` на доступном из интернета компьютере/VPS и сообщить адрес; без этого relay не появится автоматически.

Даже с relay нельзя обещать отсутствие лагов или разрывов при очень слабом/нестабильном канале. Он решает проблему маршрута, а не качества линии.

## Что пока не проверено именно в Donorcraft

Upstream Horizon публикует подписанные сборки и проверяет запуск своих Windows-программ в CI, но это не заменяет тест на твоём компьютере. Отдельный Donorcraft game binary, публичный relay и реальный совместный тест двух игроков из этого репозитория ещё не опубликованы. Если первый запуск прошёл, следующий полезный шаг — проверить приглашение и соединение с другом.
